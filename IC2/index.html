Event listener adalah function yang dijalankan browser ketika event tertentu terjadi pada elemen, misalnya klik pada tombol.

addEventListener memisahkan JavaScript dari HTML sehingga struktur, tampilan, dan perilaku tetap terpisah dan lebih mudah dirawat.
